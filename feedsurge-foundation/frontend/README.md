# FEEDSURGE frontend

The supplied official app icon is at `../assets/feedsurge-app-icon.jpg`.

The frontend is intentionally not wired to production services in this foundation package. The next implementation stage will build the mobile-first FEEDSURGE interface and connect it through a typed service layer to the staging API.

Brand requirements:
- Keep the official camera/lightning app icon unchanged.
- Keep the cyan, blue and purple gradient family.
- Preserve the user's established FEEDSURGE look and app-like navigation.
- No fake engagement counts or fabricated activity.
